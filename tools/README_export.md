# Конвертер старой переписки Telegram → текст для ИИ

Программа `tg_export_to_text.py` превращает экспорт чата из Telegram Desktop в
короткие текстовые файлы того же вида, что выдаёт мост (`get_unprocessed`).
Работает только с файлом на вашем компьютере и ничего не отправляет в интернет.

## Шаг 1. Скачайте историю чата из Telegram Desktop

1. Откройте нужный чат в **Telegram Desktop** (программа на компьютере, не в браузере).
2. Нажмите **⋮** в правом верхнем углу → **Экспорт истории чата**.
3. Снимите все галочки с фото, видео, голосовых и файлов: нужен только текст.
4. **Формат** — выберите **JSON** (машиночитаемый).
5. Нажмите **Экспортировать**. Появится папка `ChatExport_…` с файлом `result.json`.

## Шаг 2. Установите Python (один раз)

Если Python уже стоит, пропустите шаг. Проверка: откройте PowerShell
(Пуск → введите «PowerShell») и выполните `python --version`. Если в ответ
пришло `Python 3.10` или новее, он есть.

Если нет: скачайте с https://www.python.org/downloads/ и при установке
обязательно поставьте галочку **Add Python to PATH**.

## Шаг 3. Скачайте программу

Откройте ссылку и нажмите кнопку загрузки (стрелка вниз, «Download raw file»):
https://github.com/mgruso/telegram-business-bridge/blob/railway-deploy/tools/tg_export_to_text.py

Положите файл `tg_export_to_text.py` в ту же папку `ChatExport_…`, где лежит `result.json`.

## Шаг 4. Запустите

1. Откройте папку `ChatExport_…` в Проводнике.
2. Щёлкните по адресной строке Проводника, наберите `powershell` и нажмите Enter:
   откроется PowerShell сразу в этой папке.
3. Выполните (дату замените на день, когда подключили мост, чтобы не задвоить
   сообщения, которые мост уже видел):

```powershell
python tg_export_to_text.py result.json --until 2026-11-23
```

Если знаете свой Telegram user id, добавьте `--owner-id 123456789`: ваши
сообщения будут помечены `[ИСХ владелец]`.

## Что получится

- Рядом появится папка **`текст_для_ИИ`** с файлами вида
  `Имя_чата_2026-03_часть1.txt`: по месяцам, большие месяцы разрезаны на
  части до ~60 тысяч символов, сообщения посередине не режутся.
- В окне будет сводка: сколько сообщений, за какой период, сколько голосовых,
  фото и файлов, и сколько файлов текста получилось.

## Ограничения

- **Голосовые сообщения**: в экспорте нет их содержания, только отметка
  «[голосовое 0:42] расшифровки нет». Сводка покажет, сколько их: это и есть
  объём информации, которую не получится восстановить.
- Фото и файлы обозначены только метками («[фото, подпись: …]», «[файл: прайс.pdf]»).
- Время берётся то, что записал экспорт (часовой пояс компьютера, на котором
  делали экспорт), смещение от UTC указано в каждой строке.
